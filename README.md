# 🎮 Jump Game — QA Testing Project

Учебный проект, включающий разработку и ручное тестирование веб-игры в стиле Doodle Jump.

Игра была самостоятельно разработана на JavaScript, HTML5, CSS и Canvas.

После разработки игры было проведено ручное тестирование основных игровых механик, пользовательского управления и интерфейса.

В ходе тестирования были выявлены дефекты, оформлены Bug Reports и подготовлена полноценная QA-документация.

Проект выполнен с целью практического применения навыков разработки и ручного тестирования в рамках подготовки к позиции Junior QA Engineer.

---

## 🎯 Цель проекта

Проверить корректность работы самостоятельно разработанной веб-игры, выявить дефекты и оформить результаты тестирования в виде полноценной QA-документации.

---

## 🐞 Найденные дефекты

### BUG-001 — Повторное приземление на одну и ту же платформу

При попытке повторно приземлиться на уже посещённую платформу происходит Game Over.

**Связанный тест-кейс:** TC-007

---

### BUG-002 — Монстры не появляются через каждые 25 платформ

Первый монстр появляется корректно, однако последующие монстры через заданный интервал платформ не появляются.

**Связанный тест-кейс:** TC-017

---

### BUG-003 — Невозможно безопасно обойти монстра

При появлении монстра отсутствует удобная возможность безопасно обойти его с другой стороны, так как дополнительная платформа расположена вплотную к основной.

**Связанный тест-кейс:** TC-018
